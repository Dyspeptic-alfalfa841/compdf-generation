<h2>📖 How to Use the Template Engine</h2>
<p>The template engine lets you create a design once and reuse it many times. Follow these steps:</p>
<ol>
  <li><strong>Create a template:</strong> Write an HTML file with placeholders like <code>{{CustomerName}}</code> or <code>{{InvoiceTotal}}</code>.</li>
  <li><strong>Prepare data:</strong> Create a simple text file or CSV file with the values you want to fill in (e.g., <code>CustomerName=John Doe</code>).</li>
  <li><strong>Run the generator:</strong> Use the command: <code>compdf-generation template.html data.txt</code></li>
  <li><strong>Get your PDF:</strong> The output will be a PDF with all placeholders replaced.</li>
</ol>

<h3>Issue 2: PDF comes out blank or corrupted</h3>
<ul>

</ul>
